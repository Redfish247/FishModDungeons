FishMod Changelog - 2026-11-09 (bugfix run 2)
==================================
Fixed:
- Garden: the pest plot box no longer stays on a plot after all its pests are gone (it was remembered from chat for up to 6 minutes).
- Seymour armor (Velvet Top Hat, Cashmere Jacket, Satin Trousers, Oxford Shoes) is no longer tagged EXOTIC, since its colors are random.
- Profile Viewer: a rejected resource listener can no longer stop /pv from finishing loading.
- Croesus loot: reward lines like "Shadow Assassin Boots" resolve to the right item even when the item name table is only partly loaded.
- Croesus loot: sign rewards now get an icon.
- Sounds: hand-typed sound names such as "Ping" or "Note Pling" now resolve instead of silently falling back.
- Connection resets and OS-localized network errors (e.g. Portuguese Windows) are no longer sent as bug reports.

FishMod Changelog - 2026-11-09
==================================
Fixed:
- Spotify HUD no longer spams your PC with background PowerShell windows/processes when Spotify isn't running or PowerShell is blocked. It now waits before retrying.
- Switching the Spotify HUD off and on quickly no longer breaks it.
- Item List: closing a screen while the search box was focused no longer leaves it "stuck", so E and your hotkeys work normally in the next chest or inventory.
- Item List: closing a screen while dragging the scrollbar no longer makes the next drag act weird.
Reported bugs fixed (from fishmod.dev):
- None this run (the site's bug list could not be read automatically).
Known issues (not fixed yet):
- 33 planned bug reports and 1 in progress on fishmod.dev were not looked at in this run.
- Pet icons in the recipe viewer may show placeholder info if opened before pet data finishes loading.
- Two Minecraft instances at once can mix up Spotify album art.
- Rare "Network Protocol Error" kick when joining Hypixel on 26.2 (cause still unknown).
